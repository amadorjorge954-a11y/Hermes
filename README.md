# Hermes

App de preventa y reparto para Vitere (canal tradicional).

| Archivo | Qué es | Enlace |
| --- | --- | --- |
| `public/index.html` | App de ruta (preventa, reparto, supervisor móvil) | https://hermes-fb9a9.web.app |
| `public/supervisor.html` | Panel de escritorio del supervisor | https://hermes-fb9a9.web.app/supervisor |

## Cómo se publica

- Cada cambio que entra a la rama `main` se publica automáticamente en producción.
- Cada pull request genera un link de prueba temporal (7 días) para revisar antes de aprobar.

Estado actual: prototipo con datos de demostración; sin base de datos en la nube todavía.
